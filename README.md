# 海外人名条批量生成（Jianying Name Entry）

在剪映专业版（Windows）中批量生成"海外人名条"竖版短视频的小工具。
带 Tkinter 界面，逐条替换字幕文字、导出、并把生成的 MP4 归置到指定目录。

## 功能

- **批量替换字幕文字**：在剪映编辑页中，对选中的字幕条逐条替换为英文名（真实键盘输入，剪映会真正提交到时间线素材）
- **自动导出**：Ctrl+M 触发导出，UIA 等待完成并自动关闭成功弹窗
- **文件归置**：导出文件按名字命名，移动到指定输出目录（默认桌面 `海外人名条\`）
- **最终位置自动归档**（v1.5.0，v1.6.0 改为批量投送）：设定一个根目录（如 `O:\AI漫剧剪辑一组`），程序按「剧名」在该目录下**自动找到对应项目文件夹**，把成片**剪切**到 `项目\人名条\` 里
  - **投送时机**：全部导出完成后统一剪切，不是出一条剪一条；只搬本次生成的成片，输出目录里的其它文件绝不会被碰；`run_log.csv` 留在输出目录
  - **人名条子目录不存在会自动创建**；跑完后自动打开的是最终位置（项目\\人名条\\）
  - **同名处理**：最终目录已有同名文件时可选 `询问`（默认，弹窗现场拍板）/ `覆盖` / `自动改名` / `跳过`；匹配失败或取消投送时文件全部留在输出目录，绝不乱放
  - 剧名在导入 CSV/TXT 时自动从文件名填入，也可手改；子文件夹名可自定义；有「匹配预览」先看会送到哪
- **断点续跑**（v1.7.0）：勾选后，已生成过的名字直接跳过，中断重跑不重复导出。判定同时看输出目录与最终目录（已投送的也算完成）；`姓名(1).mp4` 归到 `姓名`，`姓名_透明.mov` 算成片附庸，不当成两条
- **强验证**：替换后读回确认文字真的被替换才导出，绝不带旧名字导出
- **失败自动跳过**：单个名字失败自动跳到下一个，结束汇总成功/失败名单
- **项目+时间归档**（v1.1.0）：填了项目名后，成片自动归档到 `输出目录/项目名_日期/`，并自动生成 `run_log.csv`（成功/失败、耗时、时间戳）
- **失败一键重跑**（v1.1.0）：跑完有失败时点亮「↻ 重跑失败」，一键重试失败的名字
- **暂停/继续**（v1.1.0）：运行中可点「⏸ 暂停」或按空格 / Ctrl+P 临时暂停与继续
- **进度高亮 + 提示音**（v1.1.0）：实时高亮当前处理的名字（黄=处理中、绿=成功、红=失败），完成/有失败时提示音提醒
- **配置中心化 + 备份/恢复**（v1.2.0）：剪映路径/输出目录/项目名/勾选项统一持久化，可导出为单个 .json 备份、换机迁移一键恢复
- **项目模板预设**（v1.2.0）：把「项目名+输出目录+勾选项」存成命名模板，下拉框一键加载/删除
- **干跑预览模式**（v1.2.0）：点「👁 干跑预览」不操作剪映，先模拟预览每个名字将导出到哪、有无同名/路径问题，契合试跑习惯
- **导出后转透明通道**（v1.3.0）：勾选后，每条 MP4 导出归置完自动用 ffmpeg 把纯黑底抠成透明，另存同名 `_透明.mov`（ProRes 4444 带 alpha），可直接叠到 PR 等软件上、无需再设滤色。ffmpeg 路径可自动探测或手动选择
- **进度高亮 + 提示音**（v1.1.0）：实时高亮当前处理的名字（黄=处理中、绿=成功、红=失败），完成/有失败时提示音提醒

## 快速使用（单文件 exe）

> 不想装 Python 环境的话，直接下载打包好的**单文件 exe** 即可运行，双击即用、自带图标。

1. 到本仓库的 [Releases](https://github.com/vhdaqd0410/Jianying-Name-Entry/releases) 页面下载最新版本的单文件 exe（`JianyingNameEntry-vX.X.X.exe`，即「海外人名条批量生成」程序，因 GitHub 资产名不支持中文故用英文命名）
2. 双击运行
3. 打开剪映专业版，进入你的草稿项目，选中字幕条
4. 输入/导入名字 → 设置输出目录 → 点"开始批量"

## 运行环境（源码运行）

- Windows + 剪映专业版
- Python 3.9+（仅需 `uiautomation` 依赖）

## 安装

```bash
pip install -r requirements.txt
```

## 使用（源码运行）

1. 打开剪映专业版，进入你的草稿项目
2. **选中字幕条**（时间轴上点一下字幕）
3. 启动程序：

```bash
pythonw gui_batch.pyw
```

或双击 `启动海外人名条.bat`。

4. 按界面提示：输入/导入名字 → 设置输出目录 → 点"开始批量"

## 从源码打包 exe

需要先安装打包依赖：

```bash
pip install pyinstaller
```

然后运行：

```bash
python -m PyInstaller gui_batch.spec --noconfirm
```

生成物在 `dist/海外人名条批量生成.exe`（单文件、嵌入图标、带版本信息）。

> **注意：必须用干净的构建目录。** 直接复用旧的 `build/` 缓存会产出打不开的 exe，
> 启动时报 `Failed to execute script 'pyiboot01_bootstrap' ... Bootloader did not set sys._pyinstaller_pyz!`。
> 遇到这种情况，把 `build/` 目录删掉（或换 `--workpath`）重新打包即可。

> **打包依赖注意（曾导致「检测一直未连接」）**：
> - `comtypes` 的子模块（尤其 `comtypes.stream`）必须显式写进 `hiddenimports`，PyInstaller 不自动全收；
> - uiautomation 自带的 `UIAutomationClient_VC140_X64/X86.dll` 必须随包放进 `uiautomation/bin/`（用 `binaries`）；
> - **不要**做 comtypes 全量枚举，会连带引入 `win32com`，其运行钩子会因缺 `pythoncom` 启动即崩。
> - 改了 spec 后跑 `python tests/test_packaging.py` 做静态校验。

## 验证脚本

`tests/` 下两个脚本可离线验证核心逻辑（不连剪映，只做文件与界面级检查）：

```bash
python tests/run_all.py              # 一次跑完全部八套
python tests/test_final_match.py     # 剧名归一化 / 项目文件夹匹配
python tests/test_deliver_batch.py   # 投送语义: 整批完成后统一剪切 / 只搬本次产物 / 四种同名策略
python tests/test_final_dir_ui.py    # 界面控件 / 配置持久化 / 同名询问弹窗
python tests/test_v170_optimize.py   # 断点续跑 / 空格热键 / 重跑不丢名单 / 窗口尺寸 / 日志 / 线程堆积
python tests/test_ui_v180.py         # 界面重塑: 关键控件可见性 / 滚动 / 折叠分组 / 宽度分配
python tests/test_title_autofill.py  # 剧名自动填入规则与边界
python tests/test_match_dialog.py    # 归档规则默认展开 / 导入后自动匹配预览 / 成功倒计时 / 失败重试

```

`test_final_match.py` 会读取真实的 `O:\AI漫剧剪辑一组` 做匹配校验；该目录不存在时自动跳过。

## 说明

- 文字替换使用真实键盘输入（点击 → Ctrl+A → Delete → 粘贴），而非 UIA SetValue（那只是显示层假替换，剪映导出时会回退）。
- 导出完成后默认**不最小化**剪映窗口。
- 控制器精简自 [capcut-mate](https://github.com/Hommy-master/capcut-mate)，仅保留导出所需能力，独立运行。
- **断点续跑**（v1.7.0）：勾选后，已生成过的名字直接跳过，中断重跑不重复导出。判定同时看输出目录与最终目录（已投送的也算完成）；`姓名(1).mp4` 归到 `姓名`，`姓名_透明.mov` 算成片的附庸，不会当成两条
- **界面重塑**（v1.8.0）：
  - **DPI 感知**：高分屏不再发虚（之前未声明 DPI 感知，2K/4K 屏整窗被系统拉伸变模糊）
  - **底部控制区固定**：开始/停止/暂停/重跑失败/进度条永远可见（之前默认 960x760 下这些控件完全不可见，必须拉大窗口才能发车）
  - **左栏可滚动**：卡片区溢出时滚轮可滚，小窗口也能触达全部设置
  - **卡片分组折叠**：输出与归档分为「保存位置 / 归档规则 / 高级选项」三组，默认只展开常用的；长标题拆行，日志栏不再被挤扁
  - **剧名自动填入**：导入 CSV/TXT 时按文件名自动填剧名（文件名就是你选的那部剧）；手动改过后本次运行内不再覆盖；重启后以下次导入为准
  - **导入后自动匹配预览**（v1.9.0）：选完 CSV/TXT 自动弹窗确认归档目标；匹配成功显示项目文件夹与投送路径，**3 秒倒计时自动关闭**；匹配失败弹窗内直接给剧名输入框，改完点「检测」，成功即转成功态并倒计时关闭（回写剧名）
  - **归档规则默认展开**：剧名/同名处理/剪切开关直接可见
  - **视觉细化**：统一配色与间距节奏（颜色/间距集中在常量里）、卡片描边、细边框输入框、原生勾选框（选中/未选中一眼可辨）

## 版本历史

- **v2.0.0**：修复打包后**检测一直未连接**（以及连带失效的批量替换导出）——根因是 spec 漏收 `comtypes.stream` 与 uiautomation 自带的两个 UIA DLL，导致每次 UIA 调用都抛 ModuleNotFoundError；「启动剪映」只用 subprocess 所以看起来正常，掩盖了问题。另修启动时日志错误地写“未检测到剪映”却又显示已连接的矛盾
- **v1.9.0**：归档规则默认展开；导入 CSV/TXT 后自动弹匹配预览（成功 3 秒倒计时自动关，失败可现场改剧名点检测重试）
- **v1.8.1**：修剧名自动填入——之前重启后上次的剧名会被误判成“手填”，导致新导入 CSV 的剧名永远填不进去
- **v1.8.0**：界面重塑（DPI 感知 / 底部控制区固定 / 左栏滚动 / 卡片折叠分组 / 长标题拆行 / 视觉细化）
- **v1.7.0**：新增「断点续跑」；修空格键吞输入（名字里带空格反而打不出来）；修「重跑失败」会覆盖全量名单；窗口尺寸记忆；日志可直接复制/导出/清空；连接状态轮询修复了并发探测堆积
- **v1.6.1**：跑完后「打开目录」改为打开最终位置（项目\\人名条\\）；未投送时回退到输出目录；`run_log.csv` 改为只留在输出目录、不随成片拷过去
- **v1.6.0**：投送改为整批完成后统一执行（不再逐条搬）；只投送本次生成的产物，输出目录里的其它文件不受影响；新增「同名处理」四种策略（询问/覆盖/自动改名/跳过），默认询问弹窗
- **v1.5.0**：新增「最终位置自动归档」——设根目录后按剧名自动匹配项目文件夹，成片剪切到 `项目\人名条\`（可切换为复制）；剧名导入 CSV 时自动填入；新增「匹配预览」；修正带项目名时成片未落到 `项目名_日期/` 子目录的 bug
- **v1.4.0**：支持把剪映导出路径直接设为输出目录，工具自动从输出目录取新文件，同盘改名归置（免去跨盘移动），批量更快
- **v1.3.1**：修复批量替换文字时字体被还原成默认的问题（替换改为「全选→直接粘贴」，保留段落字体格式）
- **v1.3.0**：导出后可选转透明通道（ProRes 4444 MOV，ffmpeg 抠黑底，可自动探测路径）
- **v1.2.0**：配置中心化 + 备份/恢复（换机迁移）；项目模板预设（保存/加载/删除）；干跑预览模式（不操作剪映先模拟预览）
- **v1.1.0**：项目名归档（`输出目录/项目名_日期/`）+ `run_log.csv` 自动记录；失败一键重跑；进度高亮；提示音；暂停/继续（空格或 Ctrl+P）
- **v1.0.5**：打包为单文件 exe、嵌入自定义图标
